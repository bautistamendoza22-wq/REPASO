# Repaso · Cuadernillo de Medicina Familiar 2026

Plan de estudio del cuadernillo de Medicina Familiar 2026, tema por tema:

- Checklist de los 144 temas con la numeración de páginas del impreso.
- Plan diario calculado según la fecha de examen de cada persona (se redistribuye si te atrasás).
- Temporizador de bloques de estudio (15/5, 25/5, 45/10).
- Flashcards verificadas contra el cuadernillo, y la opción de agregar las propias.
- Anotador de distracciones.

El progreso se guarda en el navegador de cada persona.
